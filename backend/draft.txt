Operant Labs Billing Platform
Backend Development & Deployment Guide
Objective
Complete the backend within one development sprint by connecting the existing frontend to production-ready services.
1. Technology Stack
	Backend: Node.js (NestJS or Express)
	Database: PostgreSQL
	ORM: Prisma
	Authentication: JWT + Refresh Tokens
	Storage: AWS S3 / Cloudflare R2
	Email: Resend or SendGrid
	PDF: PDFKit or Puppeteer
	Payments: Stripe/PayPal (future ready)
	Deployment: Docker + VPS or Railway/Render
2. Backend Modules
	Authentication & Roles
	Client Management API

	Invoice Line Items

	PDF Generator

7. Deployment
	Purchase/assign subdomain (e.g. billing.operantlabs.io)
	Deploy frontend (Vercel)

	Deploy PostgreSQL database
	Configure environment variables

	Enable HTTPS
	Configure backups and monitoring
